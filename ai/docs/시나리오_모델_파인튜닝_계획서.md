## 1. 개요

### 1.1 목표
밈과 제품을 활용한 숏폼 광고 시나리오의 **대사(Dialogue)** 생성 모델 파인튜닝

### 1.2 2-Stage 아키텍처

```
┌─────────────────────────────────────────────────────────────┐
│  사용자 입력                                                 │
│  ├── 밈 선택 (DB에서)                                       │
│  ├── 제품 정보                                              │
│  ├── 캐릭터 (이름, 페르소나)                                 │
│  ├── 배경 (카페, 사무실, 헬스장 등)                          │
│  └── 톤 (유쾌, 병맛, 감동, 진지)                             │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Stage 1: SkeletonGenerator (GPT-4)                         │
│  ─────────────────────────────────────────────────────────  │
│  • 밈과 제품의 창의적 연결                                    │
│  • 전체 스토리 흐름 설계                                      │
│  • 밈이 터지는 포인트 결정                                    │
│                                                             │
│  Output: Skeleton (스토리 뼈대)                              │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│  Stage 2: DialogueGenerator (파인튜닝 모델) ⭐               │
│  ─────────────────────────────────────────────────────────  │
│  • Skeleton 기반 실제 대사 생성                              │
│  • 캐릭터 페르소나에 맞는 말투                                │
│  • key_phrase 자연스럽게 삽입                                │
│  • 일관된 JSON 포맷 출력                                     │
│                                                             │
│  Output: 완성된 시나리오 JSON                                │
└─────────────────────────────────────────────────────────────┘
```

### 1.3 왜 2-Stage인가?

| 단계 | 특성 | 적합한 모델 |
|------|------|------------|
| Skeleton | 창의적 연결 필요, 밈↔제품 매칭 | GPT-4 (창의성) |
| Dialogue | 일관된 포맷, 반복 패턴 | 파인튜닝 (비용↓ 일관성↑) |

**파인튜닝이 Dialogue에 적합한 이유:**
- 높은 호출량 (모든 사용자 요청) → 비용 절감
- 일관된 JSON 포맷 → 학습 용이
- 캐릭터/톤 매핑 패턴 → 학습 가능
- 창의성보다 일관성 중요 → 파인튜닝 적합

## 3. Stage 1: SkeletonGenerator (GPT-4)

### 3.1 역할
- 밈과 제품의 **창의적 연결점** 찾기
- 전체 스토리 **흐름 설계**
- 밈이 **자연스럽게 터지는 포인트** 결정

### 3.2 Input

```python
skeleton_input = {
    "meme": {
        "name": "운동 많이 된다",
        "key_phrase": "운동 많이 된다",
        "definition": "힘든 일을 유머러스하게 표현",
        "emotion": "playful",
        "usage_examples": [...]
    },
    "product": {
        "name": "핏블리 프로틴",
        "category": "건강식품",
        "key_point": "단백질 30g, 맛있음"
    },
    "characters": [
        {"name": "민수", "persona": "헬스 초보, 20대 대학생"},
        {"name": "준혁", "persona": "헬창, 운동 자랑 많음"}
    ],
    "setting": "헬스장",
    "tone": "유쾌"
}
```

## 4. Stage 2: DialogueGenerator (파인튜닝)

### 4.1 역할
- Skeleton을 바탕으로 **실제 대사** 생성
- 캐릭터 페르소나에 맞는 **말투 반영**
- **key_phrase** 자연스럽게 삽입
- 일관된 **JSON 포맷** 출력

## 5. 학습 데이터

### 5.1 데이터 포맷 (Qwen Chat Template)

```json
{
  "messages": [
    {
      "role": "system",
      "content": "너는 시나리오 대사 작가야. 주어진 스토리 뼈대(skeleton)와 캐릭터 정보를 바탕으로 자연스러운 대사를 작성해. 캐릭터의 페르소나에 맞는 말투를 사용하고, 밈의 key_phrase를 대화에 자연스럽게 삽입해."

    {
      "role": "user",
      "content": "## Skeleton\n{skeleton_json}\n\n## 밈\n- key_phrase: \"운동 많이 된다\"\n- emotion: playful\n\n## 제품\n- name: 핏블리 프로틴\n- key_point: 단백질 30g, 맛있음\n\n## 캐릭터\n- 민수: 헬스 초보, 20대 대학생\n- 준혁: 헬창, 운동 자랑 많음\n\n## 배경: 헬스장\n## 톤: 유쾌"

      "role": "assistant",
      "content": "{완성된 시나리오 JSON}"

  ]
```

### 5.2 데이터 다양성 매트릭스

| 차원 | 종류 | 예시 |
|------|------|------|
| **캐릭터 관계** | 5종 | 친구, 직장, 가족, 연인, 낯선 사람 |
| **캐릭터 연령대** | 4종 | 10대, 20대, 30대, 40대+ |

| **톤** | 4종 | 유쾌, 병맛, 감동, 진지 |

## 7. 학습 코드

### 7.1 전체 학습 스크립트

```python
from unsloth import FastLanguageModel
from trl import SFTTrainer, SFTConfig
from datasets import load_dataset

# ============================================
# 1. 모델 로드
# ============================================
model, tokenizer = FastLanguageModel.from_pretrained(
    model_name="unsloth/Qwen2.5-7B-Instruct-bnb-4bit",
    max_seq_length=4096,
    load_in_4bit=True,
    dtype=None,
)

# ============================================
# 2. LoRA 어댑터 추가
# ============================================
model = FastLanguageModel.get_peft_model(
    model,
    r=32,
    lora_alpha=64,
    target_modules=[
        "q_proj", "k_proj", "v_proj", "o_proj",
        "gate_proj", "up_proj", "down_proj",
    ],
    lora_dropout=0.05,
    bias="none",
    use_gradient_checkpointing="unsloth",
    random_state=42,
)

# ============================================
# 3. 데이터셋 로드
# ============================================
dataset = load_dataset(
    "json",
    data_files="data/dialogue_dataset.jsonl",
    split="train"
)
dataset = dataset.train_test_split(test_size=0.1, seed=42)

# ============================================
# 4. Trainer 설정 & 학습
# ============================================
trainer = SFTTrainer(
    model=model,
    tokenizer=tokenizer,
    train_dataset=dataset["train"],
    eval_dataset=dataset["test"],
    args=SFTConfig(
        output_dir="./dialogue-generator-lora",
        learning_rate=2e-4,
        per_device_train_batch_size=4,
        gradient_accumulation_steps=4,
        num_train_epochs=3,
        fp16=True,
        logging_steps=10,
        eval_strategy="epoch",
        save_strategy="epoch",
        max_seq_length=4096,
    ),
)

trainer.train()

# ============================================
# 5. 저장
# ============================================
model.save_pretrained("./dialogue-generator-lora")
tokenizer.save_pretrained("./dialogue-generator-lora")

# GGUF 변환 (Ollama용)
model.save_pretrained_gguf(
    "./dialogue-generator-gguf",
    tokenizer,
    quantization_method="q4_k_m"
)
```

## 8. 추론 파이프라인

### 8.1 전체 흐름

```python
from openai import OpenAI
from unsloth import FastLanguageModel

# GPT-4 클라이언트
openai_client = OpenAI()

# 파인튜닝 모델 로드
dialogue_model, dialogue_tokenizer = FastLanguageModel.from_pretrained(
    model_name="./dialogue-generator-lora",
    max_seq_length=4096,
    load_in_4bit=True,
)
FastLanguageModel.for_inference(dialogue_model)


def generate_scenario(user_input: dict) -> dict:
    """
    2-Stage 시나리오 생성

    Args:
        user_input: {meme, product, characters, setting, tone}

    Returns:
        완성된 시나리오 JSON
    """
    # Stage 1: Skeleton (GPT-4)
    skeleton = generate_skeleton(user_input)

    # Stage 2: Dialogue (Fine-tuned)
    scenario = generate_dialogue(skeleton, user_input)

    return scenario


def generate_skeleton(user_input: dict) -> dict:
    """Stage 1: GPT-4로 스토리 뼈대 생성"""

    response = openai_client.chat.completions.create(
        model="gpt-4o",
        messages=[
            {"role": "system", "content": SKELETON_SYSTEM_PROMPT},
            {"role": "user", "content": format_skeleton_input(user_input)}
        ],
        response_format={"type": "json_object"},
    )

    return json.loads(response.choices[0].message.content)


def generate_dialogue(skeleton: dict, user_input: dict) -> dict:
    """Stage 2: 파인튜닝 모델로 대사 생성"""

    # 입력 포맷팅
    prompt = format_dialogue_input(skeleton, user_input)

    messages = [
        {"role": "system", "content": DIALOGUE_SYSTEM_PROMPT},
        {"role": "user", "content": prompt}
    ]

    inputs = dialogue_tokenizer.apply_chat_template(
        messages,
        tokenize=True,
        add_generation_prompt=True,
        return_tensors="pt",
    ).to("cuda")

    outputs = dialogue_model.generate(
        input_ids=inputs,
        max_new_tokens=2048,
        temperature=0.7,
        top_p=0.9,
    )

    response = dialogue_tokenizer.decode(outputs[0], skip_special_tokens=True)

    # JSON 파싱
    return extract_json(response)
```

```python
5. 포맷 준수: JSON 구조가 올바른가?

## 입력 정보
{input_info}

## 생성된 시나리오
{scenario}

JSON으로 평가 결과를 제공해줘.
"""
```

### 9.2 자동 검증

```python
def validate_scenario(scenario: dict, input_info: dict) -> dict:
    errors = []

    # 1. JSON 구조 검증
    required_fields = ["title", "scenes"]
    for field in required_fields:
        if field not in scenario:
            errors.append(f"Missing field: {field}")

    # 2. key_phrase 포함 여부
    key_phrase = input_info["meme"]["key_phrase"]
    dialogues = " ".join([s["dialogue"] for s in scenario.get("scenes", [])])
    if key_phrase not in dialogues:
        errors.append("key_phrase not found in dialogues")

    # 3. 캐릭터 이름 일치
    input_names = {c["name"] for c in input_info["characters"]}
    scene_names = {s["character"] for s in scenario.get("scenes", [])}
    if not scene_names.issubset(input_names):
        errors.append("Unknown character in scenes")

    return {"valid": len(errors) == 0, "errors": errors}
```
