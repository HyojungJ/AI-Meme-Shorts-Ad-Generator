# 밈 데이터 수집 요구사항 정의서

## 개요

본 문서는 밈 영상 자동 생성 서비스의 **밈 데이터 수집** 기능에 대한 요구사항을 정의한다.

---

## 요구사항 목록

| 분류 | 중분류 | 요구사항 ID | 요구사항명 | 요구사항 상세설명 |
|------|--------|-------------|------------|-------------------|

| 데이터 수집 | 기본 정보 | REQ-COL-004 | 밈 유형 분류 | 시스템은 밈을 대사형(quotable), 퍼포먼스형(performable), 복합형(hybrid)으로 GPT-4o를 통해 분류해야 한다. 검수: 10개 샘플 밈 대상 분류 정확도 90% 이상. |
| 데이터 수집 | 기본 정보 | REQ-COL-005 | 다중 소스 수집 | 시스템은 나무위키, 네이버, YouTube 등 2개 이상의 외부 소스에서 정보를 수집해야 한다. 검수: sources 배열에 2개 이상 소스명 포함 확인. |

| 데이터 수집 | 기본 정보 | REQ-COL-007 | 신뢰도 점수 산정 | 시스템은 수집에 사용된 소스 개수를 기반으로 신뢰도를 산정해야 한다. (1개: 0.5, 2개: 0.75, 3개 이상: 0.9~1.0) 검수: confidence가 0~1 범위인지 확인. |
| 데이터 수집 | 영상 분석 | REQ-COL-008 | 레퍼런스 영상 검색 | 시스템은 YouTube Data API를 사용하여 밈 관련 영상을 검색해야 한다. 검수: 검색된 영상 제목에 밈 이름이 포함되어 있는지 확인. |
| 데이터 수집 | 영상 분석 | REQ-COL-009 | 출처 기반 영상 검색 | 시스템은 수집된 출처 정보(크리에이터명, 원본 콘텐츠명)를 YouTube 검색 쿼리에 포함해야 한다. 검수: 검색 쿼리 로그에 크리에이터/출처명 포함 확인. |
| 데이터 수집 | 영상 분석 | REQ-COL-010 | 영상 프레임 분석 | 시스템은 Gemini 2.0 Flash Vision을 사용하여 영상에서 8개 프레임을 추출하고, 포즈/제스처/표정/카메라 앵글을 분석해야 한다. 검수: video_analysis.motion_analysis 필드 존재 확인. |
| 데이터 수집 | 영상 분석 | REQ-COL-011 | 동작 프롬프트 생성 | 시스템은 Gemini Vision 분석 결과를 GPT-4o로 변환하여 카메라 앵글, 동작 시퀀스, 표정을 포함한 영어 프롬프트를 생성해야 한다. 검수: motion_prompt에 camera, movement, expression 관련 단어 포함 확인. |
| 데이터 수집 | 영상 분석 | REQ-COL-012 | 스타일 키워드 생성 | 시스템은 GPT-4o를 사용하여 영상의 시각적 스타일을 나타내는 영어 키워드를 5개 이상 생성해야 한다. 검수: style_keywords 배열 길이 5 이상 확인. |
| 데이터 수집 | 영상 분석 | REQ-COL-013 | 레퍼런스 영상 정보 저장 | 시스템은 수집된 YouTube 영상의 video_id, URL, 제목, 조회수를 저장해야 한다. 검수: reference_videos 배열에 url 필드 포함 확인. |

| 데이터 수집 | 오디오 분석 | REQ-COL-016 | BPM 분석 | 시스템은 librosa를 사용하여 음성의 BPM을 분석해야 한다. 검수: bpm 필드가 0보다 큰 숫자인지 확인. |
| 데이터 수집 | 오디오 분석 | REQ-COL-017 | 피치 분석 | 시스템은 librosa를 사용하여 음성의 평균 피치(Hz)를 분석해야 한다. 검수: avg_pitch_hz 필드가 0보다 큰 숫자인지 확인. |
