## 개요
### 작업 내용
- LTX-2를 활용한 **씬 단위 영상 생성 파이프라인 설계**
- 텍스트, 오디오, 이미지 입력을 조합한 영상 생성 방식 정의
- Mock 모드로 씬 단위 영상 생성 파이프라인 검증
- 모델 다운로드없이 전체 흐름(입력→프롬프트→출력→저장)이 동작하는지 확인


### 주요 기능
1. Text / Audio / Image 입력 기반 씬 단위 영상 생성
2. 오디오 분석 결과를 모션 프롬프트로 변환하여 씬별 입력에 반영 (별도 분석)
3. 씬 간 연속성을 고려한 참조 이미지를 씬별 입력에 반영
4. 씬 단위 mp4를 최종 영상으로 합치는 단계인 최종 합성 노드 (미구현)
5. `scene_videos`, `videos` DB 저장 (미구현)

### 오디오 분석 → 모션 변환 개요
- LTX-2는 기본적으로 텍스트/이미지 기반이며, 오디오를 네이티브 컨디셔닝하지 않음
- 음성 입력은 별도 분석 단계를 거쳐 모션 힌트로 변환 후 사용
- 스택: `webrtcvad` + `librosa` (음성 구간 + 에너지 추출)

## 입력/출력
### 입력
- **텍스트**
  - 장면 설명 (인물, 동작, 감정, 분위기)
- **오디오**
  - 음성
  - 리듬·타이밍·에너지 정보는 별도 분석 단계에서 추출
- **이미지**
  - 캐릭터 참조 이미지 또는 이전 씬 마지막 프레임

### 출력
- **씬 단위 영상 파일 (.mp4)**
  - 립싱크 후처리에 적합한 화질 및 프레임 유지
  - 오디오 포함 또는 분리 저장 가능

## 실행/테스트 방법
### 1. 환경 변수 설정
```
LTX2_MODE=mock
```

### 2. 실행 방법
```powershell
uv run python -m scripts.video_generate_test `
  --prompt "energetic talking head, punchline delivery" `
  --reference-image-path "data/images/nanobanana_1769018375.png"
```

샘플 mp4로 대체하려면 다음 옵션을 사용한다.
```powershell
uv run python -m scripts.video_generate_test `
  --prompt "energetic talking head, punchline delivery" `
  --mock-sample-path "data/video/sample.mp4"
```
