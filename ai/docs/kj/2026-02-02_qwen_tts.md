## 개요
- ElevenLabs와 분기 처리하여 `VOICE_PROVIDER=qwen` 설정 시 Qwen3 TTS 기반으로 음성 생성
- 오픈 소스 기반이라 초기 모델 로딩 시간이 비교적 김
- **Design → Clone** 흐름으로 동작
  - Design 모델로 참조 음성 생성
  - Base 모델로 clone prompt 생성 후 S3에 저장
- qwen-tts 의존성 필요 (torch/transformers 포함)

## 환경 변수
필수/권장 항목:
- `VOICE_PROVIDER=qwen`
- `QWEN_TTS_BASE_MODEL_ID` (기본: `Qwen/Qwen3-TTS-12Hz-1.7B-Base`)
- `QWEN_TTS_VOICE_DESIGN_MODEL_ID` (기본: `Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign`)
- `QWEN_TTS_DEVICE` (예: `cpu`, `cuda:0`, `auto`)
- `QWEN_TTS_DTYPE` (예: `float32`, `float16`, `bfloat16`)
- `QWEN_TTS_ATTN_IMPL` (예: `flash_attention_2`)
- `QWEN_TTS_SEED` (기본: `42`)

## 동작 흐름
1) `design_voice_node_qwen()`  
   - 입력: `text`, `voice_name`, `voice_description`, (옵션) `design_text`
   - 단계:
     - VoiceDesign 모델로 참조 음성 생성
     - Base 모델로 clone prompt 생성
     - clone prompt를 `safetensors`로 저장 후 S3 업로드
   - 출력: `voice_id(qwen3:clone:...)`, `voice_sample_url`, `clone_prompt_url`

2) `generate_voice_node_qwen()`  
   - 입력: `text`, `voice_id`, (옵션) `clone_prompt_url`
   - 동작: clone 경로 사용 (Base 모델 + clone prompt)
   - 출력: 최종 음성 파일 URL/저장 경로

## 트러블슈팅

1. Qwen TTS 음색 변동 (legacy 경로 이슈)
- 문제: legacy(design/custom) 경로에서 `( … )` cue가 instruct를 덮어쓰면 음색이 흔들릴 수 있음
- 변경: legacy 경로 제거, clone 경로만 사용하도록 정리
- 이전 동작: `qwen3:design:*` / `qwen3:custom:*` 경로를 허용하며 `( … )` cue로 instruct를 덮어썼음
- 현재 동작: `qwen3:clone:*` 경로만 사용하고 clone prompt로 음색을 고정

2. 백그라운드 캐릭터/음성 생성 태스크 불안정
- 원인: BackgroundTasks와 asyncio.create_task가 혼재되어 중복 실행/이벤트루프 충돌 가능 
- 해결: BackgroundTasks 단일 경로로 통일
   - `asyncio.create_task` 제거
   - `_generate_character_and_voice_background` 동기화 후 `asyncio.run` 실행

3. Windows CRLF로 인한 bash 실행 오류
- 원인: CRLF 줄바꿈이 bash 스크립트 해석을 깨뜨림
- 해결: 원격 merge 스크립트 줄바꿈 강제
   - `NamedTemporaryFile(..., newline="\\n", encoding="utf-8")` 적용
