# 영상처리 기반 생성물 자동 검사

AI가 생성한 이미지·영상의 품질을 **OpenCV로 자동 검사**하고,
기준에 못 미치는 결과물은 사람 개입 없이 다시 생성하도록 만든 기능입니다.

> 밈 기반 숏폼 광고 자동 생성 프로젝트의 일부로, 생성물 품질 검사 부분을 정리한 문서입니다.

---

## 왜 만들었나

AI 생성 모델은 가끔 못 쓰는 결과물을 만듭니다.

- 흐릿하게 뭉개진 이미지
- 너무 어둡거나 하얗게 날아간 이미지
- 전체가 한 가지 색으로 깨진 화면
- 거의 검은 화면만 나오는 영상
- 크기나 비율이 맞지 않는 결과물

이런 결과물을 사람이 매번 눈으로 확인하면 느리고 일관성도 떨어집니다.
그래서 **품질을 수치로 측정해 기준에 못 미치면 자동으로 걸러내는** 검사 단계를 만들었습니다.

---

## 어떻게 검사하나

OpenCV로 이미지·영상에서 값을 측정하고, 미리 정한 기준값과 비교해 통과/실패를 판정합니다.

### 이미지
| 검사 항목 | 측정 방법 |
|-----------|-----------|
| 선명도(흐림) | 라플라시안 분산 — 경계가 얼마나 뚜렷한지 수치화 |
| 밝기(노출) | 전체 픽셀의 평균 밝기 |
| 화면 깨짐 | 픽셀 값의 표준편차 — 거의 한 색이면 깨진 화면 |
| 해상도 | 가로·세로 픽셀 수 |
| 화면 비율 | 가로/세로 비율 (세로형 기준) |

### 영상
| 검사 항목 | 측정 방법 |
|-----------|-----------|
| 재생 가능 여부 | 영상 파일 열기 시도 |
| 길이·프레임 수 | 프레임 개수와 재생 시간 |
| 검은 화면 비율 | 여러 프레임을 뽑아 밝기 측정 |
| 전반적 선명도 | 프레임별 선명도 평균 |

---

## 불량이면 자동으로 다시 생성

검사 결과를 생성 과정에 연결했습니다.

```
생성 → [OpenCV 검사] → 통과하면 다음 단계로
                     → 실패하면 자동 재생성 (정해진 횟수까지 반복)
```

- OpenCV 검사를 먼저 돌려 명백한 불량을 빠르게 걸러냅니다.
- 이 단계에서 걸러지면 뒤의 무거운 검사(AI 모델 호출)를 생략해 시간과 비용을 아낍니다.
- 재시도 횟수를 넘기면 사람에게 확인을 요청합니다.

---

## 신경 쓴 점

- **기준값을 코드 바깥에서 바꿀 수 있게** 설계해, 결과물 특성에 맞춰 선명도·밝기 기준을 쉽게 조정할 수 있습니다.
- **실패 이유를 함께 기록**합니다. "밝기가 너무 낮음", "흐림 수치 미달"처럼 원인을 남겨 분석에 활용할 수 있습니다.
- **정상·불량 샘플을 직접 만들어 검증**했습니다. 흐린 이미지, 어두운 이미지, 깨진 화면, 검은 영상을 만들어 모두 올바르게 분류되는지 확인했습니다.
